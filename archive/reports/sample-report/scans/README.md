# scans/

Optional page images used to check difficult readings during transcription and QA (for example, high-resolution captures of a degraded table or a faded appendix).

Scans are working evidence, not the preserved source. The authoritative file is always the unmodified PDF in `../source/`.

The sample report was born digital, so no scans are needed. In a real report, name scans by PDF page index, for example `page-034.png`, and mention them in the QA notes for the record.
